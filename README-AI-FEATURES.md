# 🤖 KSYK Maps - AI Features

## Welcome to the Future of Campus Navigation! 🚀

KSYK Maps now includes comprehensive AI capabilities powered by **Google Gemini AI** through **Firebase AI Logic SDK**.

## 🎯 Quick Start

### Access AI Features
1. **Click** the purple "✨ AI Assistant" button in the header
2. **Or navigate** to `/ai-assistant`
3. **Choose** from 8 specialized tools + 3 additional features

### Main AI Hub - 8 Tools
1. **💬 Chat Assistant** - Study Buddy & Campus Guide
