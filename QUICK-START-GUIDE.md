## Start Using Now

### 1. Start Server
```bash
npm run dev
```

### 2. Login
Go to: `http://localhost:5000/admin-login`

### 3. Access Wilma
Click "Wilma" in the admin navigation

## Test These Features

### ✅ View Students
- Go to "Opiskelijat" tab
- Click "Katso" on any student
- See full student profile with tabs

### ✅ View Parents  
- Go to "Huoltajat" tab
- Each parent shows "1 opiskelija linkitetty"
- Parents are properly linked to students

### ✅ Manage Schedule
- Go to "Lukujärjestys" tab
- Add lessons to weekly grid
- Filter by class

### ✅ Configure Settings
- Go to "Asetukset" tab
- Edit all school settings
- Save changes

### ✅ Send Messages
- Go to "Viestit" tab
- Compose and send messages
- View inbox/sent
