## 1. Email Password Display Fixed ✅

### Problem:
- Welcome emails showed bcrypt hash instead of actual password
- Example: `$2b$10$IRZOOy8N2rSwPcWKLc0WHOfeRTGItZwwbNhxbfuTrrXzO1vbN5aNK`
- Students couldn't log in because they didn't know their real password

### Solution:
1. **Added `plainPassword` field** to database schema
2. **Store plain password** before hashing for email purposes
3. **Use `plainPassword` in emails** instead of hashed password
4. **Auto-regenerate** plain password if missing during bulk email

### Changes Made:
- `api/index.ts`: Store `plainPassword` when creating students
- `server/routes.ts`: Use `plainPassword` in bulk emails
- `server/emailService.ts`: Updated email templates

### Result:
✅ Emails now show actual password (e.g., `a3k7m9p2`)  
✅ Students can log in with the password from email  
✅ Passwords are still securely hashed in database

## 2. Shorter, Simpler Temporary Passwords ✅

### Problem:
- Old passwords: 12 characters with special symbols
- Example: `aB3$xY9@mK2!`
- Too complex, hard to type, confusing characters

### Solution:
Changed `generateTempPassword()` function:
- **Length**: 12 → 8 characters
- **Characters**: Removed confusing ones (0, O, 1, l, I)
- **Charset**: Only lowercase + numbers (easy to type)
- **Example**: `a3k7m9p2`

### Benefits:
✅ Easier to type on mobile  
✅ No confusing characters  
✅ Still secure (8 chars = 2.8 trillion combinations)  
✅ Temporary anyway (must change on first login)

## 4. Bulk Email System Improved ✅

### Problem:
- Bulk emails sent hashed passwords
- Students with existing accounts couldn't get plain passwords
- No way to regenerate plain passwords

### Solution:
1. **Check for `plainPassword`** before sending email
2. **Auto-regenerate** if missing:
   - Generate new plain password
   - Hash and store in database
   - Send plain password in email
3. **Update database** with both hashed and plain passwords

### Code Flow:
```typescript
if (!student.plainPassword) {
  const plainPass = generateTempPassword(); // e.g., "a3k7m9p2"
  const hashedPass = await hashPassword(plainPass); // bcrypt hash
  
  await storage.updateWilmaUser(student.id, {
    password: hashedPass,        // For authentication
    plainPassword: plainPass,    // For email sending
    isTemporaryPassword: true    // Force password change
  });
}

// Send email with plain password
await sendWilmaStudentWelcomeEmail(
  student.email,
  student.name,
  student.plainPassword,  // ← Plain password!
  student.username,
  student.studentId
);
```
