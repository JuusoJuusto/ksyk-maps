# Wilma Login Background Image

## How to Add a Custom Background

1. **Place your image** in this folder (`client/public/`)
2. **Name it**: `wilma-bg.jpg` (or `wilma-bg.png`, `wilma-bg.webp`)
3. **Recommended specs**:
   - Resolution: 1920x1080 or higher
   - Format: JPG, PNG, or WebP
   - File size: Under 500KB (optimized)
   - Aspect ratio: 16:9 or wider

## Image Guidelines

- **Theme**: School/education related (campus, books, students, etc.)
- **Colors**: Works best with blue tones (matches Wilma theme)
- **Brightness**: Medium to dark images work best (overlay is applied)
- **Contrast**: Avoid very busy images (text needs to be readable)

## Examples of Good Backgrounds

- School building exterior
- Library interior
- Classroom with natural light
- Books and study materials
- Abstract education-themed patterns
- Campus landscape

## Technical Details

The image will be:
- Covered across the full screen
- Blended with a blue gradient overlay (90% opacity)
- Combined with a subtle dot pattern
- Optimized for all screen sizes

## Fallback

If no image is found, the login page will use the default blue gradient background.

## Testing

After adding your image:
1. Refresh the Wilma login page
2. Check on different screen sizes
3. Verify text is still readable
4. Ensure the image loads quickly
