
   - Map tab: Interactive campus map

   - Book tab: Room booking interface
   - Services tab: Campus services browser
   - Profile tab: User stats and settings

2. **Access 3D Builder**:
   ```
   Navigate to: /builder-3d
   ```
   - Switch view modes (3D/2D/Split)
   - Use editing tools to modify map
   - Export your 3D model

3. **Original Home** (Still Available):
   ```
   Navigate to: /
   ```

   - Classic KSYK Maps interface

1. **Start Development Server**:
   ```bash
   npm run dev
   ```


