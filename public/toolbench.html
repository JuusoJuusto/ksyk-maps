About KSYK Toolbench

A small offline utility for surveying classrooms and managing the KSYK Maps platform. Save this HTML file to your desktop and double-click to open — it works without an internet connection apart from when it talks to the KSYK server.

Web Bluetooth beacon scanning works in Chrome / Edge on Windows and macOS. GPS uses the browser's geolocation API. WiFi BSSID scanning isn't exposed by browsers — use your phone's WiFi info tool and paste readings here.

Tip: rename to ksyk-toolbench.hta on Windows to launch it as a self-contained "HTML Application" without browser chrome.
