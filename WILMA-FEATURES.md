## 📝 API Endpoints Summary

- **Authentication:** Login, logout, password reset
- **Users:** CRUD operations for all user types
- **Schedule:** View, create, update, delete
- **Grades:** View, create, update, delete, summary
- **Assignments:** View, create, submit, grade, delete
- **Messages:** Send, receive, read, delete, threads
- **Attendance:** Mark, view, summary, excuse
- **Exams:** Schedule, view, update, results
- **Courses:** Browse, enroll, manage, materials
- **Teachers:** Directory, profiles, contact
- **Rooms:** Directory, details, booking, map
- **Announcements:** Create, view, update, delete
- **Classes:** Manage, roster, schedule
- **Materials:** Upload, download, organize
- **Notifications:** Create, view, mark read
- **Parent-Student:** Link, manage, permissions
