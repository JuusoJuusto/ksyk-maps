# 🗺️ KSYK Maps

Interaktiivinen kampusnavigointijärjestelmä Kulosaaren Yhteiskoululle (KSYK).

[![Versio](https://img.shields.io/badge/versio-2.0.1-blue.svg)](https://github.com/JuusoJuusto/ksyk-maps)
[![Lisenssi](https://img.shields.io/badge/lisenssi-Proprietary-red.svg)](LICENSE)

## ✨ Ominaisuudet

### 🧭 Navigointi
- Google Maps -tyylinen reittisuunnittelu
- A* reitinhakualgoritmi
- Animoitu reitin visualisointi
- Monikerroksinen navigointi

### 🏢 Kampuksen Hallinta
- Interaktiiviset rakennus- ja huonekartat
- Henkilöstöhakemisto haulla
- Reaaliaikaiset ilmoitukset
- Monikielinen tuki (EN/FI)

### 🎨 Käyttökokemus
- Tumma tila
- Mobiiliresponsiivinen suunnittelu
- Sulava animaatio
- Ammattimainen käyttöliittymä

## 🛠️ Teknologiat

- **Frontend**: React, TypeScript, Tailwind CSS
- **Backend**: Node.js, Express
- **Tietokanta**: Firebase Firestore
- **Julkaisu**: Vercel
