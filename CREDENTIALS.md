## 🔧 Creating New Users

### Via Wilma Admin Panel:
1. Login as admin at `/wilma`
2. Navigate to admin panel (if admin/teacher/principal)
3. Go to "Users" tab
4. Click "Add User"
5. Fill in details
6. Select role(s) - can select multiple!
7. Optional: Enable "Send email invitation"
8. Click "Create User"

### Multiple Roles Example:
A user can have multiple roles simultaneously:
- Teacher + Admin
- Teacher + Counselor
- Principal + Teacher
- Admin + IT Support

## 🔒 Security Best Practices

1. **Change Default Passwords**:
   - All default passwords should be changed immediately
   - Use strong passwords (min 12 characters)
   - Include uppercase, lowercase, numbers, symbols

2. **Enable 2FA** (when available):
   - Authenticator app support
   - Email verification
   - Backup codes

3. **Regular Password Updates**:
   - Change passwords every 90 days
   - Never reuse old passwords
   - Use unique passwords for each account

4. **Access Control**:
   - Only grant necessary permissions
   - Review user access regularly
   - Disable inactive accounts
